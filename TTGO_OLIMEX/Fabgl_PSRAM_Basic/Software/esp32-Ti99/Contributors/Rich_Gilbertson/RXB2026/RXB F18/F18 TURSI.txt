1) Correct. the GPU runs 9900 code from VDP RAM at roughly 100MHz. 
It's very fast and has direct access to VDP RAM (but NO access to the rest of the system). 
So you get the assembly bytes and copy them somewhere safe in VDP RAM.
2) To start the GPU, you use registers 54 and 55. 
Write the MSB of the starting address to 54, and the LSB to 55. 
Writing the LSB also starts the GPU automatically. 
So in my example code above, if you uploaded it to VDP >1000, 
then MAGIC would be at >1000, and CODE would be at >1002. 
So we would write >10 (or 16) to register 54, then write >02 (or 2) to register 55. 
The GPU would then start immediately. In that code, all it would do is SETO at >1000 (in VDP RAM),
 and then IDLE which stops the GPU again.
